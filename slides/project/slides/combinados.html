O que sai daqui escrito

Antes de pedir código

  • A spec diz o que é “pronto”?
  • A regra do legado foi conferida na fonte?
  • A skill certa existe? Se já fiz três vezes à mão, deveria existir
  • O pedido é análise ou implementação? Diga qual

Os combinados do time

  • Quem é dono do CLAUDE.md de cada repo
  • Quais três skills o time cria no primeiro mês
  • Qual é a definição de pronto na Supridata
  • Nenhum [x] sem evidência com data

Laboratório: pegue um item pendente do roadmap, escreva a §0, implemente com a skill, rode o teste, volte a evidência para o roadmap.

Avaliação: não é “funcionou?”. É outra pessoa consegue retomar isso amanhã lendo só os arquivos?

Revisão em duas semanas, sobre as skills que o time escreveu de verdade

Não termine com aplausos: termine com os combinados preenchidos num arquivo, no repositório deles. Marque a sessão de revisão de 1h antes de todos saírem da sala — é onde o padrão pega ou morre.
