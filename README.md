# Treinamento — Desenvolvimento com IA na Supridata

Material do treinamento de desenvolvimento assistido por IA (Claude Code) para o time da Supridata,
montado a partir dos padrões já em uso nos projetos `sysenota`, `syscomm`, `sysepesquisa`,
`syseprotocolo` e `syseassociacao`: memória (`CLAUDE.md` / `AGENTS.md`), roadmap com evidência,
specs numeradas e skills com `references/` e `scripts/`.

**Turma:** 3 devs Java/Angular que já usam o Claude Code. Formato: workshop de teclado.
**Duração:** em aberto — a grade é modular (ver o guia do instrutor).

## O que tem aqui

| Arquivo | Para quem | O que é |
|---|---|---|
| [guia-do-instrutor.md](guia-do-instrutor.md) | você | Grade modular, roteiro de cada bloco, o que abrir na tela, exercícios, conselhos de execução |
| [apostila-aluno.md](apostila-aluno.md) | os devs | Referência de consulta com exercícios para preencher, cola de uma página e os compromissos pós-treinamento |
| [templates/](templates) | os devs | `CLAUDE.md.modelo`, `NNN-tema.spec.md.modelo`, `SKILL.md.modelo` — em branco, comentados, prontos para copiar para os repositórios |

Os slides ficam num deck separado (link no guia do instrutor), com notas do apresentador em cada
slide e exportação para PowerPoint ou PDF.

## Antes do treinamento

1. Confirmar o formato e reservar a sala e as datas (grade modular no guia, §2).
2. Garantir que os três têm o repositório clonado e a pilha local subindo.
3. Imprimir a cola da apostila (§11) e colocar os `templates/` nos repositórios do time.
4. Escolher o item `[ ]` do roadmap que vai servir de laboratório final.

## Depois

Revisão de 1h duas semanas depois, sobre as skills que o time escreveu de verdade. É onde o padrão
pega ou morre.
